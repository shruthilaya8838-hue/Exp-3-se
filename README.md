# Exp - 3 RAILWAY MANAGEMENT SYSTEM

# AIM:

To design and develop a Railway Management System using StarUML by creating UML diagrams to represent the structure and behaviour of the railway reservation system, including passengers, trains, tickets, and reservations.

# SRS (Procedure):
Open the StarUML application.

Create a new project and select the UML model.

Identify the main entities involved in the Railway Management System, such as Passenger, Train, Ticket, and Reservation.

Create a Use Case Diagram to represent the interactions between passengers and the railway system.

Create a Class Diagram with suitable attributes and operations for each class.

Create a Sequence Diagram to show the interaction between the passenger and the railway system during ticket booking.

Create an Activity Diagram to represent the workflow of ticket reservation and cancellation.

Establish the relationships between classes using association, aggregation, and inheritance where required.

Verify all diagrams and ensure they are properly connected.

Save the project and generate the final UML diagrams.
